# Agent instructions

## Integration branch

Agents do not branch from `main` or open pull requests to `main` for ordinary work. Branch from `agent-dev`, push your branch, report, and the integrator merges it into `agent-dev`. Pull requests to `main` are only for exempt work and for the batch pull request. Full rules, local check commands and exemptions: [docs/agents/integration-branch.md](docs/agents/integration-branch.md).
